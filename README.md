# UC-MSC 肺損傷課堂文字雲

這是一個使用 Firebase Cloud Firestore 的即時文字雲網頁。使用者送出關鍵字後，資料會寫入 `wordcloud_words` 集合，所有開啟頁面的裝置會即時同步更新。

## Firebase

- Firebase project：`ring-ktpei`
- Firestore collection：`wordcloud_words`
- Web App：`ucmsc-wordcloud-web`

## 本機開啟

可以直接開啟 `index.html`，或用靜態伺服器預覽。

## 部署

本專案預計部署至 GitHub Pages。
